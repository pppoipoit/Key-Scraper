==========================================================
LaptopKey Scraper - Elite Edition v2 (Multi-URL Parallel Engine)
==========================================================
เขียนโดย: ซานต้าคลอดด์ 🎀
สำหรับ: เจ้านาย (Tokenmee)

----------------------------------------------------------
1) โครงสร้างไฟล์ (แยกเป็น module ตามที่สั่ง)
----------------------------------------------------------
main.py              -> จุดเริ่มโปรแกรม (รันไฟล์นี้เพื่อเปิดแอป) + ตั้ง icon title bar
app.py               -> ประกอบหน้าจอ UI ทั้งหมด + จัดการ event / threading
scraper_core.py       -> Logic ดูดข้อมูล/ดาวน์โหลดรูป (ใช้ร่วม/ทดสอบแยกจาก UI ได้)
gradient_widgets.py   -> Custom widget (ปุ่ม/การ์ด/progress bar) แบบ gradient+เงา+มุมโค้ง
theme.py              -> รวมสี/ฟอนต์/ขนาดทั้งหมดของแอป (แก้สีธีมที่นี่ที่เดียว)
icon.ico             -> ไอคอนเริ่มต้น (โทนชมพู-ม่วงตามธีม) ใช้กับ title bar/exe ได้เลย
requirements.txt      -> รายชื่อ library ที่ต้องติดตั้งก่อนรัน

----------------------------------------------------------
2) วิธีรันตอน Dev (ทดสอบก่อน build)
----------------------------------------------------------
pip install -r requirements.txt
python main.py

----------------------------------------------------------
3) วิธี Build เป็น .exe (เหมือนเดิมที่เจ้านายใช้ PyInstaller)
----------------------------------------------------------
แนะนำ --onedir (เปิดแอปเร็วกว่า + เหมาะกับทำ Inno Setup installer ต่อ):

  python -m PyInstaller --noconsole --onedir --icon=icon.ico main.py

แอปจะอยู่ที่ dist\main\ (เปลี่ยนชื่อ exe/โฟลเดอร์ได้ด้วย --name "Key_Scraper")

  python -m PyInstaller --noconsole --onedir --icon=icon.ico --name "Key_Scraper" main.py

----------------------------------------------------------
4) ฟีเจอร์ใหม่ใน v2
----------------------------------------------------------
- ใส่ URL ได้หลายอัน (1 บรรทัด = 1 ลิงก์) ในกล่อง TARGET URLs
  ระบบจะดูดข้อมูลพร้อมกันสูงสุด 4 URL ในเวลาเดียวกัน (ปรับได้ที่ MAX_PARALLEL_URLS ใน app.py)
- ช่อง Log และช่อง URL เลื่อนเมาส์ขึ้น-ลงได้ (มี scrollbar ด้วย)
- มีแถบ progress bar แบบ gradient บอกว่าทำงานไปกี่ URL แล้ว (ไม่โชว์ %)
- UI ธีมเข้มสไตล์ dashboard ตามภาพตัวอย่างที่เจ้านายส่งมา (gradient + เงา + มุมโค้ง)
- Icon ที่ title bar (ใช้ icon.ico ที่แถมมา หรือเปลี่ยนเป็นไฟล์ของเจ้านายเองได้
  โดยแก้ตัวแปร ICON_FILENAME ในไฟล์ main.py)

----------------------------------------------------------
5) สิ่งที่ตรวจสอบแล้วก่อนส่งมอบ (เทียบกับโค้ดต้นฉบับ)
----------------------------------------------------------
✅ เทียบ logic ดาวน์โหลด/แยกโฟลเดอร์กับ Key_Scraper.py ต้นฉบับ -> โครงสร้างไฟล์/โฟลเดอร์
   และเนื้อไฟล์ที่ดาวน์โหลด "ตรงกัน 100%" (รันเทสต์อัตโนมัติเทียบ byte-by-byte แล้ว)
✅ ทดสอบ end-to-end ผ่านหน้า UI จริง: กรอกหลาย URL พร้อมกัน -> log/progress bar/
   ปุ่ม Start อัพเดทถูกต้อง -> โฟลเดอร์ผลลัพธ์รวมจากหลาย URL ไม่ทำให้โครงสร้างเพี้ยน
✅ เจอและแก้บัค thread-safety จริงระหว่างเทสต์ (อ่านค่ากล่อง URL/destination ต้องทำที่
   main thread เท่านั้น ก่อนส่งต่อให้ background thread ทำงาน ไม่งั้นมีโอกาส error
   บางเครื่อง/บาง Python version)
✅ โครงสร้างโฟลเดอร์ปลายทาง 4 หมวด (Layout / LARGER KEYS / REGULAR KEY / SMALLER KEYS)
   และชื่อโฟลเดอร์แบรนด์ "ไม่ถูกแก้ไขเลยแม้แต่ตัวอักษรเดียว" ตามที่สั่งเด็ดขาด

----------------------------------------------------------
6) ถ้าจะเปลี่ยนสีธีม/หน้าตา
----------------------------------------------------------
แก้ที่ theme.py ไฟล์เดียว (มีคอมเมนต์อธิบายทุกค่าสีว่ามาจากการ์ดไหนในภาพตัวอย่าง)
