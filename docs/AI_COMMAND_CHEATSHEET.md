# คลัง Prompt สำหรับเจ้าของที่ไม่เขียนโค้ด

## 1. เริ่มวางแผนงานจาก CURRENT_TASK
\"อ่าน docs/HANDOFF.md, docs/CURRENT_TASK.md, docs/04_DECISIONS.md และเอกสารที่เกี่ยวข้องก่อน เริ่มจากสรุปความเข้าใจ แผน ไฟล์ที่จะกระทบ ความเสี่ยง และวิธีทดสอบ แล้วรออนุมัติก่อนแก้โค้ด\"

## 2. อนุมัติแผน
\"APPROVE PLAN. ให้ Cline เริ่มทำตามแผนที่อนุมัติแล้ว\"

## 3. ขอแก้แผน
\"ขอแก้แผน [ระบุส่วนที่ต้องแก้]. ให้ Cline อธิบายวิธีแก้เป็นภาษาคน และบอกว่ามีอะไรเสี่ยง\"

## 4. สั่งให้ทำต่อหลังอนุมัติ
\"Cline อนุมัติแผนแล้ว ให้ทำต่อตามแผนที่อนุมัติ แต่ถ้าพบปัญหาให้หยุดและถามฉันก่อน\"

## 5. รายงานบั๊ก
\"# Bug report
- สิ่งที่ฉันทำ:
- สิ่งที่คาดหวัง:
- สิ่งที่เกิดขึ้นจริง:
- ข้อความ error:
- เกิดซ้ำได้หรือไม่:
- รูป/ข้อมูลเพิ่มเติม:\"

## 6. ขอให้ Cline อธิบายเรื่องเทคนิคแบบง่าย
\"อธิบาย [เรื่องนี้] แบบคนไม่เขียนโค้ด ให้เข้าใจง่ายๆ และบอกว่ามันส่งผลอะไรกับฉัน\"

## 7. ขอให้ Cline สรุปสิ่งที่เปลี่ยนจาก git diff เป็นภาษาคน
\"ตรวจ git diff แล้วสรุปเป็นภาษาคนว่า file อะไรเปลี่ยนไป ทำอะไร และมีอะไรเกิน scope ไหม\"

## 8. ขอขั้นตอนทดสอบแบบกดตามได้
\"ขอขั้นตอนทดสอบแบบ non-developer กดตามได้ โดยไม่ต้องอ่านโค้ด\"

## 9. สั่งปิดงานและอัปเดต HANDOFF
\"งานนี้เสร็จแล้ว ให้สรุปผลลัพธ์ อัปเดต docs/HANDOFF.md และบอกว่าฉันต้องทำอะไรต่อ\"

## 10. สั่งตรวจงานก่อน commit
\"ตรวจงานก่อน commit สรุปว่า file อะไรเปลี่ยนไปเป็นภาษาคน และบอกว่ามีอะไรเกิน scope ไหม\"

## 11. อนุมัติ commit
\"APPROVE COMMIT. ทำ commit และบอกผลลัพธ์ เช่น commit hash และ message\"

## 12. เปิด New Task ต่อจาก HANDOFF
\"เปิด New Task ต่อจาก docs/HANDOFF.md โดยให้เริ่มจาก Exact next task และส่งแผนให้ฉันอนุมัติก่อนแก้โค้ด\"

## 13. ย้ายไป AI chat ใหม่โดยใช้ HANDOFF
\"ฉันกำลังย้ายไป AI chat ใหม่ ให้อ่าน docs/HANDOFF.md, docs/CURRENT_TASK.md, docs/04_DECISIONS.md และเริ่มจาก Exact next task\"

## 14. สั่งให้หยุดงานเมื่อพบเรื่องเสี่ยง
\"Cline หยุดงานทันที! พบเรื่องเสี่ยง [ระบุ]. ให้ส่งสรุปและรอฉันอนุมัติก่อนทำอะไรต่อ\"

## 15. สั่งให้สร้าง task ใหม่จากไอเดียภาษาคน
\"ฉันมีไอเดียใหม่: [อธิบายเป็นภาษาคน]. ขอให้ Cline ช่วยสร้าง task ใหม่ใน docs/CURRENT_TASK.md พร้อม Goal, Scope, Non-goals และ Acceptance criteria แต่ห้ามเดา business rule\"

## กติกาใช้ Prompt

- Prompt ทุกอันต้องบอกชัดว่า Cline ห้ามเดา
- บอกให้ตอบเป็นภาษาคน
- บอกให้ถามเฉพาะเรื่องที่ block งาน
- ห้ามส่งหลายงานใน prompt เดียว
