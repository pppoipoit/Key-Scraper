# เริ่มตรงนี้ก่อน

## โปรเจกต์นี้ทำงานยังไง

- **เจ้าของโปรเจกต์**: คิดสิ่งที่อยากให้แอปทำ, ดูผลลัพธ์, ทดสอบ, อนุมัติ
- **Cline**: อ่านเอกสาร, วางแผน, เขียนโค้ด, ทดสอบ, สรุปงาน
- **docs/**: สมุดความจำของโปรเจกต์
- **Git**: ปุ่มเซฟเกมและปุ่มย้อนเวลาเมื่อโค้ดพัง

## กฎ 5 ข้อที่เจ้าของต้องจำ

1. ทำทีละงาน ห้ามสั่งหลายฟีเจอร์ปนกัน
2. ให้ Cline เสนอแผนก่อน แล้วค่อยอนุมัติ
3. ต้องลองกดทดสอบเองก่อนบอกว่างานผ่าน
4. งานผ่านแล้วค่อย commit เพื่อเซฟสถานะ
5. ถ้าไม่เข้าใจ ให้ถาม Cline ว่า “อธิบายแบบคนไม่เขียนโค้ด และบอกฉันทีละขั้นว่าต้องทำอะไร”
