## สิ่งที่ตรวจพบใน repo (สรุป)
- **Stack**: Python 3 + tkinter, requests, beautifulsoup4, Pillow, PyInstaller, Inno Setup
- **Language**: Python 3.x (tkinter GUI)
- **Dependencies**: requests, beautifulsoup4, Pillow
- **ไม่มี database** - แอปเดสก์ท็อปสแตนด์อัลน์
- **ไม่มี authentication/authorization**
- **Thread safety สำคัญ** - UI ต้องแก้จาก main thread เท่านั้น
- **Folder structure คงที่** - ต้องรักษา 4 หมวด + ชื่อแบรนด์ (ตามที่สั่งเด็ดขาด)
- **สีธีมและ widget แบบ custom** - ใช้ PIL เพราะ tkinter ไม่ native support

## วิธีใช้หลังจากนี้

### ตอนเริ่มฟีเจอร์ใหม่
1. อ่าน docs/HANDOFF.md และ docs/CURRENT_TASK.md
2. อ่าน docs/00_PRODUCT.md และ docs/01_REQUIREMENTS.md
3. Cline เสนอแผน (ต้องรออนุมัติเจ้าของ)
4. ถ้าอนุมัติ → Cline เริ่มทำงาน
5. ทดสอบตาม Manual Test Steps
6. สั่ง "APPROVE COMMIT" ถ้าผ่าน
7. อัปเดต HANDOFF.md

### ตอนจบ task
1. ทดสอบว่างานผ่านแล้ว
2. สั่ง "APPROVE COMMIT"
3. รอ Cline commit และอัปเดต HANDOFF.md
4. ตรวจสอบว่า git diff ไม่มีของนอก scope

### ตอนย้ายไป New Task หรือเปลี่ยน AI chat
1. ให้ Cline อัปเดต docs/HANDOFF.md ก่อนจบงาน
2. เปิด New Task หรือ AI chat ใหม่
3. อ่าน HANDOFF.md, CURRENT_TASK.md, DECISIONS.md
4. เริ่มจาก Exact next task

## คำถามที่ต้องตอบเพื่อเริ่มเก็บ Product Context (ไม่เกิน 12 ข้อ)

1. แอปนี้แก้ปัญหาอะไรเป็นหลัก (ช่วยให้ผู้ใช้ดึงรูปคีย์บอร์ดจากเว็บไซต์ได้ง่ายขึ้น)
2. ใครใช้ (เจ้าของ/ลูกค้ารายเดียวหรือหลายคน)
3. user role มีอะไรบ้าง (ตอนนี้มี 1 Roll: Operator)
4. ฟีเจอร์แรกที่สำคัญที่สุดคืออะไร (multi-URL parallel scraping)
5. อะไรคือสิ่งที่ห้ามทำ (เปลี่ยนโครงสร้างโฟลเดอร์/ชื่อแบรนด์โดยไม่ได้รับอนุมัติ)
6. มีระบบ login/payment/data สำคัญหรือไม่ (ไม่มี - เดสก์ท็อปสแตนด์อัลน์)
7. นิยามความสำเร็จของ MVP คืออะไร (ดึงรูปได้ครบ โฟลเดอร์ถูกต้อง ไม่ค้าง)
8. มีเว็บไซต์เป้าหมายกี่เว็บ (เปิดรับได้ทุกเว็บที่มีโครงสรucture ตามที่คาด)
9. MAX_PARALLEL_URLS ต้องเป็นเท่าไหร่ (ค่าเริ่มต้น 4 แต่สามารถปรับได้)
10. ต้องรองรับ macOS/Linux หรือไม่ (ตอนนี้ Windows เป็นหลัก)
11. ต้องการ automated test หรือไม่ (ตอนนี้มี manual test เท่านั้น)
12. มีข้อจำกัดด้านสี/รูปแบบอื่นที่ต้องรู้หรือไม่ (ต้องรักษา color palette จาก theme.py)
